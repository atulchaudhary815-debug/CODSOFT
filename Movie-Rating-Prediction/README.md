# Movie Rating Prediction

## Overview
This project predicts movie ratings using Machine Learning techniques. The model is trained on movie-related data and learns patterns from various features to estimate the rating of a movie.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Algorithm
- Random Forest Regressor

## Dataset
The dataset contains movie information such as:
- Movie Name
- Genre
- Director
- Actors
- Year of Release
- Duration
- Votes
- Rating

## Project Workflow
1. Import Dataset
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Train-Test Split
5. Model Training using Random Forest Regressor
6. Model Evaluation
7. Rating Prediction
