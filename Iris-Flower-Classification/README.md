# Iris Flower Classification

## Overview
This project classifies Iris flowers into three different species: Setosa, Versicolor, and Virginica using Machine Learning techniques. The model is trained on the famous Iris dataset and predicts the species based on flower measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Algorithm
- Decision Tree Classifier

## Dataset Features
The dataset contains the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Target
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Project Workflow
1. Import Dataset
2. Data Exploration
3. Data Preprocessing
4. Train-Test Split
5. Model Training using Decision Tree Classifier
6. Model Evaluation
7. Species Prediction
